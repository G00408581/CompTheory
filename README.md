# Computational Theory Assessment

This repository contains my solutions to the Computational Theory assessment (Winter 26/27), based on the Secure Hash Standard (FIPS 180-4).

## Setup

1. Clone the repository: `git clone https://github.com/G00408581/CompTheory.git`
2. Install the packages: `pip install -r requirements.txt`
3. Open the notebook: `jupyter notebook problems.ipynb`

## Contents

- `problems.ipynb`: the notebook with all problems.
- `requirements.txt`: the Python packages needed.
